# Art direction - approved correction

The user explicitly requested a Chinese anime mobile game (??) look inspired by Honkai: Star Rail. The initial realistic fantasy artwork was rejected and has been replaced.

## Visual rules
- Fine ink linework, expressive anime faces, flat local colors, crisp two-tone cel shading.
- Original sci-fi character fashion and silhouettes; no existing franchise characters or copied logos.
- Ink navy backgrounds, ivory controls, restrained gold rarity markers, periwinkle and cyan accents.
- Angular panel geometry, thin dividers, bold clean headings, generous negative space.
- The summon screen is artwork-led, with a clear featured character and two unmistakable pull actions.
- Avoid medieval ornament, excessive bloom, generic glass cards, dashboard-like charts, and text over busy faces.
- Every interaction must work on touch and keyboard. Reduced motion and Skip must preserve identical rewards.
