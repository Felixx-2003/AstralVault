# Astral Vault — approved plan

Status: Approved. Implementation in progress.

- Team: main agent reviews artwork and browser UX; one GPT-6 Luna Max codes.
- Design: crisp anime sci-fi art, ink navy, restrained gold and white controls, premium mobile/desktop UI, readable stats, polished collection and shop screens.
- Cards: rarity, element, role, HP, attack, defence, and unique skill.
- Gameplay: collect cards, form teams, complete simple battles and daily missions for free currency.
- Summoning: single/10 pulls, rarity-specific portal/reveal animation, Skip, results, published odds and pity guarantee.
- Economy: earnable free currency and a disabled paid-currency shop until a recoverable account and verified payment provider are configured. The server owns all balances and rewards.
- Stages: secure Worker/D1 game API and rules, responsive playable loop, tests, polish and deployment documentation.
