# Project collaboration rules

These preferences were explicitly set by the user on 2026-09-28 and apply throughout this project.

- The main agent plans and coordinates; coding agents implement changes.
- Verify code with type checks, production builds and meaningful automated tests. Fix failures before delivery.
- The user personally evaluates visuals and gameplay experience, then provides feedback. Do not run visual browser reviews, manual gameplay sessions or unsolicited appearance/game-feel polishing unless the user asks for them again.
- Implement the agreed features, make the working build available, and wait for the user's playtest feedback before further visual or experiential changes.
- Keep user-facing updates and final reports brief. Do not ask again for actions already authorized in the conversation.
- Maintain organized folders and concise, useful READMEs. Keep credentials and generated local state out of Git.
