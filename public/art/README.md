# Character artwork

The PNG portraits and featured banner are original anime sci-fi illustrations created for Astral Vault. The short asset list and prompt provenance are in [`../../docs/art-direction.md`](../../docs/art-direction.md).

Catalog image paths are root-relative URLs such as `/art/kael-rowanveil.png`. Keep filenames stable or update the matching character entry in `src/shared/catalog.ts`.
